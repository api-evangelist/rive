# Rive

> Rive is an interactive design and animation platform and real-time graphics engine. Designers, animators, and developers create, animate, and code interactive experiences in one place and ship them across every platform via open-source native runtimes. Built around a State Machine design system and a GPU-accelerated vector renderer (up to 120fps), Rive exports a single lightweight .riv file driven at runtime. There is no hosted REST API; the developer surface is the family of first-party runtime SDKs plus data binding, Luau scripting, and CDN share/embed hosting.
